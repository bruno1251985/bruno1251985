## Engineering interests

- Modelling business rules and separating them from HTTP and persistence concerns.
- Choosing an architecture that fits the product: a separate frontend and API, or a simpler server-rendered application.
- Evolving relational data with explicit migrations and testing against PostgreSQL.
- Keeping changes small, documenting decisions and considering deployment and recovery early.

## Technologies used in my projects
